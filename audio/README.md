# Add Your Audio Files Here

Place your MP3, WAV, or other audio files in this directory.

The filenames should match what you specify in the `songs` array in `index.html`.

Example:
- song1.mp3
- song2.mp3
- my-favorite-track.mp3
- etc.

Make sure to update the `index.html` file with the correct:
- title
- artist
- duration
- filename (must match the actual file)
- icon (any emoji)
